## 固定IP、原生IP、静态IP：先把三个词分清楚

固定IP解决的是“地址不变”：不管重连多少次，对方看到的都是同一个IPv4。账号平台判定异常操作的一个重要依据就是IP频繁变动，所以在养号场景里，静态IP基本算刚需。

原生IP则是另一回事，它指的是这段IP资源本身就归属台湾本地ISP，而非从其他地区广播过来。平台风控会查ASN、地理信息和ISP归属三项，原生IP三项都能过，广播IP经常缺项。动画疯在这方面的验证出了名的严，台湾广播IP基本打不开，它也成了检验“真原生”最直接的试金石。

下单前把两件事分开确认：先问IP是不是原生，再确认是静态还是动态。静态IP不提供更换，适合长期养号；动态IP可以一键换新，适合起号、多账号轮换这类场景。买反了，钱就花在了不对的地方。另外，台湾原生IP资源本身就不多，能稳定拿到全新IP段的商家更少——丽萨主机的台北机房给的正是全新段，拿到手先测一下欺诈分，指标干净再投入使用。
